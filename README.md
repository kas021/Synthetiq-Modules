# Synthetiq Modules

Binary-only module catalogue for Synthetiq Player. Import this repository once:

`https://github.com/kas021/Synthetiq-Modules`

The app checks this catalogue only when a repository-linked module is actively
selected. Updates are always shown to the user before installation.

## Contents

- Bundle 80 bootstrap package
- 12 immutable versioned module packages
- Signed `repository.json`
- SHA-256 checksums

Editable module source code is intentionally not published here.
